02 — HOW I WORKطريقة الشغل

Video as codeالفيديو كأنه كود

Instead of a timeline that only I can open, every project is a small program: change a line, re-render, done.بدل تايملاين ما حدا بيفتحه غيري، كل مشروع عبارة عن برنامج صغير: بتغيّر سطر، بتطلّع الفيديو من جديد، وخلص.

1

Script & storyboardالنص والستوري بورد

From a brief, a PDF or raw footage to a scene-by-scene plan the client approves.من البريف أو ملف PDF أو اللقطات الخام لخطة مشهد بمشهد بيوافق عليها العميل.

2

Build scenesبناء المشاهد

React components in Remotion: typography, icons, transitions, brand colours as tokens.مكوّنات React بـ Remotion: الخطوط، والأيقونات، والانتقالات، وألوان البراند بقيم ثابتة.

3

Soundالصوت

Original music and SFX synthesized in Python, locked to the same timeline.موسيقى ومؤثرات أصلية بـ Python، مربوطة بنفس التايملاين.

4

Deliverالتسليم

FFmpeg master: platform-ready H.264, −14 LUFS loudness, short cuts from the same project.نسخة نهائية بـ FFmpeg: جاهزة لكل منصة، والصوت مضبوط على −14 LUFS، والنسخ القصيرة من نفس المشروع.

I work with an AI-assisted workflow (Claude Code) for writing and reviewing code — the creative direction, decisions and delivery are mine.بشتغل بمساعدة الذكاء الاصطناعي (Claude Code) بكتابة الكود ومراجعته، أما الرؤية الإبداعية والقرارات والتسليم فهي إلي.
