هذا الإعداد مرة واحدة بس، وبعدها البيانات بتتزامن تلقائياً على كل أجهزتك

الخطوة 1

روح على console.firebase.google.com وسجّل دخول بحساب Google

الخطوة 2

اضغط "Add project" ← سمّيه مثلاً my-supermarket ← اضغط Continue حتى ينتهي

الخطوة 3

من القائمة الجانبية اختر Firestore Database ← Create database ← اختر Start in test mode ← Next ← Enable

الخطوة 4

من أيقونة الترس ⚙️ ← Project Settings ← Your apps ← أيقونة </> ← سجّل التطبيق ← انسخ الكود والصقه هون
